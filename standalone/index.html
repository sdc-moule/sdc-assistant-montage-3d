Groupes de sélection

Un groupe garde des pièces sous un nom (ex. « partie injection »). Cliquer un groupe le sélectionne ; il sert à isoler, masquer, éclater (« Sélection seulement ») ou déplacer (« Déplacer » → onglet Démonter). Enregistré avec le projet.

Reste à faire

Cocher « fini » quand une pièce est usinée (par repère : toutes ses occurrences). Les pièces achetées (vis, écrous, rondelles, joints, bagues, colonnes) sont détectées d'après la désignation — proposé, corrigeable — et ne comptent pas dans le reste à faire.

Ouverture paramétrée

Simuler l'ouverture du moule ou d'un élément : sélectionner les pièces mobiles, choisir le mouvement, créer le groupe, puis glisser « Fermé → ouvert ». Plusieurs groupes s'enchaînent (ex. plaque qui coulisse puis volet qui pivote). Aucun contrôle mécanique n'est fait.

Utilisation

  • Tourner : glisser avec un doigt / clic gauche. Déplacer : deux doigts / clic droit. Zoom : pincer / molette.
  • Sélectionner : toucher une pièce, une ligne de l'arborescence, de la nomenclature ou une bulle. Toucher le vide pour désélectionner.
  • Plusieurs pièces : Ctrl + clic, « Multi », ou fenêtre (« ▭ Fenêtre » ou Maj + glisser) : de gauche à droite = pièces entièrement dans le cadre, de droite à gauche = pièces touchées.
  • Raccourcis : H masquer, I isoler, A tout afficher, F cadrer, Échap désélectionner, Ctrl+Z/Y.
  • Perçages & circuits : les forages sont détectés sur le maillage d'affichage. Les diamètres et longueurs sont indicatifs ; les taraudages ne sont pas détectables.
  • Aucun calcul de collision, de jeu, de tolérance ou de serrage n'est réalisé. Le fichier STEP n'est jamais modifié.
